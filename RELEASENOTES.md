# v4.2.RC1 Release Notes

## Nederlandse uitleg
Deze release notes bevatten eerst de Nederlandse versie en daarna de Engelse versie. Deze release candidate gebruikt Chrome-manifestversie `4.2.1` voor updates en toont `4.2.RC1` als zichtbare versie.

## Nederlandse versie

### Changelog v4.2.RC1
- **Ticket Check Chat:** Nieuwe TCC-verzoek- en antwoordtemplates met een vaste V&A/TCC-domeinswitch, TCC-validatie en ondersteuning in preview, Teams-kopie en vertaling.
- **Live CRS-notitie:** Tijdens een actief TCC-verzoek wordt de CRS-notitie live bijgewerkt. Bij lokale wijzigingen kies je expliciet tussen de CRS- of templateversie.
- **CRS-screenshotcapture:** De compacte `📸`-knop legt de zichtbare CRS-pagina vast voor Klantvraag, Antwoord en TCC Screenshots. De sidebar wordt kort verborgen zodat hij niet op de afbeelding staat.
- **Screenshot verwijderen:** Elke gemaakte screenshot heeft een klein `×`-kruis rechtsboven om hem direct met de muis te verwijderen. Dit bedieningsonderdeel wordt nooit meegenomen in preview of Teams-kopie.
- **Betere capturefouten:** Chrome-toestemmingsfouten voor screenshots geven nu een bruikbare melding in plaats van een stille generieke mislukking.

### Installatie Instructies
1. Download het `.zip` bestand en pak het uit
2. Ga in Chrome naar `chrome://extensions/`
3. Zet rechtsboven de slider op Developer mode (Ontwikkelaarsmodus) aan
4. Klik op Load unpacked (Uitgepakte extensie laden)
5. Selecteer de uitgepakte map

Of download `standalone-template-v[versie].html` en open dit direct in je browser.

## English version

### Changelog v4.2.RC1
- **Ticket Check Chat:** New TCC request and answer templates with a persistent Q&A/TCC domain switch, TCC validation, and support in preview, Teams copy, and translation.
- **Live CRS note:** During an active TCC request, the CRS note updates live. After local changes, you explicitly choose between the CRS or template version.
- **CRS screenshot capture:** The compact `📸` button captures the visible CRS page for Customer question, Answer, and TCC Screenshots. The sidebar briefly hides so it is excluded from the image.
- **Remove screenshots:** Every captured screenshot has a small top-right `×` control to remove it directly with the mouse. This control is never included in preview or Teams copy.
- **Improved capture failures:** Chrome screenshot permission failures now show an actionable message instead of a silent generic failure.

### Installation Instructions
1. Download the `.zip` file and extract it
2. Open `chrome://extensions/` in Chrome
3. Enable the **Developer mode** toggle in the top-right corner
4. Click **Load unpacked**
5. Select the extracted folder

Or download `standalone-template-v[version].html` and open it directly in your browser.
